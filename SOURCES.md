# Sources / 来源

- Eat source code: Rotten-flower, MIT.
- Release icon: AI-generated from this project’s actual in-game feeding capture; AI image generation and code assistance were used during development.
- Minecraft models, textures, food rules, sounds and particles: Minecraft by Mojang Studios / Microsoft. The mod references installed game resources; extracted game resource files are not bundled in this repository.
- Forge, Fabric API and NeoForge are external dependencies resolved by Gradle under their own licenses. Optional mod integrations use those mods’ runtime behavior; their code and assets are not bundled.

- Eat 自有代码：Rotten-flower，MIT。
- 发布图标：依据本项目真实游戏截图使用 AI 生成，开发过程中使用了 AI 辅助代码与生图。
- 原版模型、贴图、食物规则、音效和粒子：Mojang Studios / Microsoft 的 Minecraft。模组引用已安装的游戏资源，仓库不附带提取的原版资源文件。
- Forge、Fabric API 与 NeoForge 为 Gradle 获取的外部依赖，遵循各自许可证。可选联动调用对应模组的运行时行为，不打包其源码和资源。
